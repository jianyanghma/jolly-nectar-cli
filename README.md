# jolly-nectar-cli

Machine Learning · WebAssembly · TypeScript

折腾中的小玩具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/jolly-nectar-cli.git
cd jolly-nectar-cli
cargo build --release
```
